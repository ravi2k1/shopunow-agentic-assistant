Why This Architecture?

Design Trade-offs & Critical Edge Case Fixes

Slide 3 / 4
Why LangGraph?

Standard chains lack cyclic memory and state control. LangGraph provides deterministic node transitions, state updates, and checkpointer persistence required for enterprise support.

Why Hybrid Search?

Dense MMR search captures semantic intent ("slow laptop"), while BM25 ensures exact keyword matches (policy IDs). Metadata filters prevent cross-department document contamination.

Edge Cases Fixed

• Prevented false escalations on problem reports ("slow laptop").
• Added Conversational route for greetings & memory meta-questions.
• Standardized string categories.
